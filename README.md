# Разноска · личный кабинет

Программа для загрузки банковской выписки, проверки операций и создания
черновиков документов в 1С (не проведённых — вы проводите их сами).

## Что уже готово
- Вход по паролю (только вы получите доступ)
- Загрузка выписки .xlsx и разбор по строкам
- Экран проверки операций с кнопкой «Подтвердить»
- Настройки подключения к вашему REST-сервису 1С
- История всех действий

## Чего ещё нет
- Реальный вызов вашего REST-сервиса 1С внутри функции `createDraftInOnec`
  в файле `server.js` — сейчас это шаблон, его нужно поправить под точный
  адрес и формат данных, которые принимает ваш сервис (адрес, как называются
  поля в запросе). Пока эта часть не настроена, кнопка «Подтвердить» будет
  выдавать ошибку — это ожидаемо.
- Категоризация через ИИ — можно добавить позже.

## Как разместить в интернете (без программирования, 10–15 минут)

Ниже — самый простой бесплатный способ, через сервис **Render.com**.

1. Зайдите на https://render.com и зарегистрируйтесь (можно через Google-аккаунт).
2. Загрузите эту папку с кодом на GitHub:
   - Зайдите на https://github.com, создайте новый репозиторий (кнопка "New").
   - Загрузите туда все файлы из этой папки (можно перетащить через браузер:
     на странице репозитория нажмите "uploading an existing file").
3. Вернитесь в Render.com → «New» → «Web Service» → выберите ваш репозиторий с GitHub.
4. В настройках сервиса укажите:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. В разделе **Environment Variables** добавьте:
   - `CABINET_PASSWORD` — придумайте свой пароль для входа в кабинет
   - `SESSION_SECRET` — любой случайный набор букв и цифр
6. Нажмите **Create Web Service**. Через пару минут Render выдаст вам
   ссылку вида `https://ваше-название.onrender.com` — это и есть ваш
   личный кабинет, доступный только тому, кто знает пароль.

Если на каком-то из шагов что-то не получится — пришлите скриншот, разберём
вместе.

## Как запустить у себя на компьютере (для проверки)
```
npm install
cp .env.example .env
# впишите свой пароль в .env
npm start
```
Откройте http://localhost:3000
